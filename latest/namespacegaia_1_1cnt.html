◆ ResizePolicy

enum class gaia::cnt::ResizePolicy : uint8_t
strong

How a dynamic array's resize() grows its capacity once the new size outgrows it.

Enumerator
Exact 

Allocate exactly the new size.

Scale 

Grow capacity by half again, as appending does, or to the new size when that is larger, so growing an array a few elements at a time relocates it only a logarithmic number of times.
