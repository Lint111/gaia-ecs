◆ PrefetchHint

enum gaia::PrefetchHint : int

Cache-locality hint accepted by prefetch().

Enumerator
PREFETCH_HINT_T0 

Temporal data — prefetch data into all levels of the cache hierarchy.

PREFETCH_HINT_T1 

Temporal data with respect to first level cache misses — prefetch data into L2 cache and higher.

PREFETCH_HINT_T2 

Temporal data with respect to second level cache misses — prefetch data into L3 cache and higher, or an implementation-specific choice.

PREFETCH_HINT_NTA 

Non-temporal data with respect to all cache levels — prefetch data into non-temporal cache structure and into a location close to the processor, minimizing cache pollution.

◆ invoke()

template<class F, class... Args>
decltype(auto) gaia::invoke ( F && f,
Args &&... args )
constexprnoexcept

Invokes a callable or a pointer to member using standard invocation semantics.

Note
Unlike std::invoke, std::reference_wrapper objects are not unwrapped for pointers to members. Pass a pointer to the object instead (e.g. invoke(&T::func, &obj)). Support is left out on purpose so <functional> is not needed. Forward-declaring std::reference_wrapper is UB (and breaks with libc++'s inline namespace), and duck-typing it could silently unwrap user types. If a real need appears, add a small gaia-owned wrapper. Wrapped callables, such as invoke(std::ref(lambda)), still work through their operator().
Template Parameters

ArgsArgument types.
Parameters
fCallable or pointer to member to invoke.
argsArguments forwarded to the callable.
Returns
The result produced by the invocation, preserving its value category.
