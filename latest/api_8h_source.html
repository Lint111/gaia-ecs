161 // Deferred sorted-query invalidation API
162 //
163 // Sorted-query invalidation flips a shared `SortEntities` dirty bit on every sorted query
164 // keyed by the written component. That shared flag is not safe to touch from a worker
165 // thread, so regions whose writes may run in parallel record which component entities were
166 // written and the coordinator applies the invalidation once the region joins. Work items
167 // identify themselves with the shared deferral slot below, which the observer (`OnSet`)
168 // channel uses as well.
169
171 inline static constexpr uint32_t BadDeferSlot = (uint32_t)-1;

186 GAIA_NODISCARD inline uint32_t& defer_slot_ref() {
187 static thread_local uint32_t s_slot = BadDeferSlot;

197 class DeferSlotScope final {
